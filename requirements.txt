# ───────────────────────────────────────────────────────────────────────────
# DELIBERATELY NOT INSTALLED
# Recording rejections is as useful as recording choices.
# ───────────────────────────────────────────────────────────────────────────
# adm-zip                — buffers the entire archive; cannot enforce limits
#                          before decompressing. Wrong tool for untrusted input.
# express / mongoose     — the spec requires a relational, type-safe stack (ADR-003)
# elasticsearch / algolia— Postgres tsvector + GIN handles this scale (ADR-008)
# redis / ioredis        — rate limiting uses a Postgres counter table for now
# trpc                   — a bespoke RPC protocol closes off REST + OpenAPI + a CLI
# clerk / auth0          — paid dependency, and teaches nothing about OAuth (ADR-004)
# zustand / redux        — catalog state lives in the URL; no client store needed
# axios                  — native fetch is sufficient and ships with the runtime
# moment / dayjs         — Intl and native Date cover every need here
# lodash                 — modern JS covers it; a whole utility library is not warranted
